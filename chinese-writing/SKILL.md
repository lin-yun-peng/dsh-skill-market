# 中文写作规范

## 标点与空格

- 中文正文用全角标点：，。、；：？！（）「」——
- 英文单词、数字、代码与中文之间留一个半角空格：`安装 Node.js 之后再执行`。
- 数字用半角，数字与单位之间不加空格：`3 个文件`、`12 GB`、`30 分钟`。
- 不要连用感叹号，不要用「~」当语气词。

## 去掉机翻腔

| 机翻腔 | 正常中文 |
| --- | --- |
| 这是一个很好的问题 | （直接回答） |
| 值得注意的是 | 注意 / 另外 |
| 在……的情况下 | 如果…… / ……时 |
| 通过使用 X 来 Y | 用 X 做 Y |
| 进行一个……的操作 | 做…… |
| 让我们来看一下 | 看 |

原则：能用一个动词就别用「进行/实现/完成 + 名词」。

## 结构

- 结论先行。先说结果，再补理由。
- 一段只说一件事，超过五行就拆。
- 并列内容用列表，有取舍关系用表格。
- 术语全文统一。不要一会儿「目录」一会儿「文件夹」，除非它们真的指两个东西。

## 交付前自查

1. 通读一遍，删掉所有可以删的字。
2. 检查中英文之间的空格是否统一。
3. 检查标点是否全角。
4. 检查有没有留下「待补充」「TODO」这类占位。
