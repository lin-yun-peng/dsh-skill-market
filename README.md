# DSH 技能货架

每个文件夹是一个可安装的 DSH 技能。安装、卸载见仓库外的 `说明.md`。

| 技能 | 说明 |
| --- | --- |
| `chinese-writing` | 中文写作与排版规范，覆盖全角半角、中英文之间加空格、数字与单位、标点、术语一致性，以及如何去掉机翻腔。当交付物是中文文档、说明、报告、README，或用户要求润色中文时使用。 |
| `skill-maker` | 教你把一份做法固化成 DSH 技能，包括目录结构、SKILL.md 的 frontmatter 写法、description 怎么写才容易被触发，以及装进技能市场的流程。当用户说「做个技能」「把这个流程存成技能」「以后都按这个来」时使用。 |
| `skill-market` | 本机 DSH 技能市场的使用手册。当用户提到技能市场、装个技能、卸载技能、有没有能做某事的技能，或问到 skill 市场相关操作时，加载本技能。里面写明市场路径、管理脚本命令和技能格式。 |

共 3 个技能。
